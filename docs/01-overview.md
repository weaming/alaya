# 01 · 总览：从哲学到底层结构

## 1. 设计缘起

本系统的目标是：为一（或多）个 AI Agent、以及它服务的个人与群体，构建一套**经得起时间考验的记忆与知识底座**。它同时要解决两个问题：

- **单次效率**：在有限上下文里，只注入该有的、不注入噪音。
- **长期表现**：跨会话保持人格同一性、累积判断、不重复犯错、随相处变好。

我们对"记忆"的立场，决定了整个系统的形态：

> **记忆不是存储，是"过去"有意义地作用于"现在"的方式。** 它的哲学内核是人格同一性与信任；它的工程责任是保存一切**不可再生成**之物——亲历的历史、被放弃的决策轨迹、主观的意义赋值。

## 2. 为什么是"多元世界"

在真实的 Agent 场景中，需要记忆的对象远不止物理现实：

- 用户的现实生活（观测流、事件、关系）；
- 用户的虚构世界投入（动漫、小说、游戏的剧情与设定——它们是**世界内部为真**的自洽系统）；
- 代码库与软件系统（每个代码库都是一个有自己法则、历史与"雷区"的小千世界）；
- 不同群体各自的约定、历史、规范（scope 化的社会性事实）。

我们拒绝"真实 = 与唯一物理现实对应"的公理，采用一个更普适的立场：

> **实在性是梯度，不是二值。** 一个世界有多"实"，取决于它的**自洽度 × 其 scope 内共识的规模与强度 × 可被参与检验的程度**。物理世界只是这个梯度上共识最大、可检验性最高的一个特例。

这个立场与佛教"三千大千世界"的宇宙观同构，详见各文档中的对应表；它的工程价值在于：**现实、虚构、代码、群体约定，可以在同一套结构里平级建模**。

## 3. 命名：Alaya（阿赖耶识）

唯识宗立八识，第八识名 **ālayavijñāna（阿赖耶识，藏识）**：含藏万法种子（bīja），刹那生灭而不失，前七识的活动与世界（器世间）皆依之变现。

| 佛教概念 | 白话 | 本系统对应 |
|---|---|---|
| 阿赖耶识 / 种子 | 含藏一切痕迹、永不消灭的底层 | **不可变基岩事件流**（一切"发生"的藏处） |
| 共业 | 一群众生共同"感"出一个世界 | **scope 化共识**：世界成立的机制 |
| 器世间 | 各有法则、自洽的时空系统 | **世界容器 World**（含世界宪章） |
| 成住坏空 | 世界的生住异灭 | **世界生命周期**（连载/完结/冷门/重启·平行世界） |
| 万法唯识 | 世界是识（共识）的变现 | **实在性梯度**：自洽 × 共识 × 可检验 |
| 转识成智 | 从杂染记录到清净智慧 | **蒸馏管道**（数据 → 事实 → 知识 → 判断） |

取名 Alaya，是提醒我们：**底层要像藏识一样忠实不灭；上层要允许世界依共识成住坏空。**

**地层隐喻**：基岩永不背叛；中间层（声称/共识/世界宪章）只增不改、可被超越不可被抹除；派生层（向量、倒排、摘要金字塔、画像）可随时推倒重建。

## 5. 分层与三台机器

### 5.1 地质分层

| 层 | 内容 | 可变性 | 真源/派生 |
|---|---|---|---|
| 基岩 Bedrock | 一切发生（real 观测 + virtual 计算 + 虚构文本事件） | 不可变，只追加 | **真源** |
| 声称 Claims | 带归属与论证的陈述（quad） | 只追加（supersedes 不删） | 真源 |
| 共识 Consensus | scope 内达成的"这里成立" | 只追加（可超越，异议永存） | 真源 |
| 世界 World | 世界宪章 + canon 分层 + 跨世界映射 | 只追加演化 | 真源（宪章） |
| 派生 Derived | 向量索引/倒排/摘要/画像/注入缓存 | 可重建、可删除 | **派生** |

### 5.2 三台机器

1. **事实裁决机**（Truth Machine）：把"声称"升级为"事实"，或降级为"存疑"。依据 = 证据链 + 反例 + 共识支持 + 世界内自洽。置信度是论证图上的可推演状态，不是写死的字段。
2. **共识机**（Consensus Machine）：在 scope 内把"我声称 P"提升为"本 scope 成立"。共业的现代认识论版本。
3. **跨世界桥**（World Bridge）：负责世界之间的参照——类比/隐喻映射、结构投影、canon 冲突的跨世界仲裁、虚拟世界的可计算推演（oracle）。

## 7. 一句话

**Alaya = 以不可变基岩忠实保存一切发生；以 scope 共识支撑无量世界各自成体；以裁决与蒸馏把数据长成可行动的判断——让 Agent 成为"被时间塑造、并记得自己为何走到这里"的存在。**
